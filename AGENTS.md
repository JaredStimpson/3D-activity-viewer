# Repository working instructions

Before planning, reviewing, or changing this repository, read `vault.md` completely.

For every material change:

- Preserve uncommitted user work.
- Follow the invariants, architecture boundaries, and verified commands in `vault.md`.
- Update stale current-state sections in `vault.md`.
- Add a concise change-ledger entry in the same commit.
- Do not store secrets, tokens, personal GPS data, generated videos, or machine-specific absolute paths in the vault.
